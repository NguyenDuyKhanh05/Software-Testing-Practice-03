# Software-Testing-Practice-03
# Bài thực hành 03 - Kiểm thử phần mềm

## Giới thiệu
Dự án thực hiện 8 bài toán cơ bản và áp dụng các kỹ thuật kiểm thử hộp đen.

## Kỹ thuật kiểm thử áp dụng
1. **Phân lớp tương đương:** Chia dữ liệu đầu vào thành các lớp hợp lệ và không hợp lệ để giảm số lượng test case cần chạy mà vẫn đảm bảo độ bao phủ.
2. **Phân tích giá trị biên:** Tập trung kiểm thử tại các ngưỡng thay đổi hành vi của chương trình (0, 1, biên của tháng, giá trị Delta = 0...).

## Cách chạy test
Sử dụng lệnh: `python -m unittest tests/test_main.py`
